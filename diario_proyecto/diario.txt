-Hemos estado pensando varios modelos de como hacer este proyecto.

-Después de barajar varias opciones, hemos optado por hacer un BI de una empresa de snaks.
Objetivo de esta fase
No vamos a programar nada todavía.
Vamos a crear el Diccionario de Datos v1.0, que será el documento base de todo el proyecto:
•	CSV iniciales 
•	PostgreSQL 
•	ETL con Pandas 
•	Dashboard Dash 
•	KPIs 
•	Automatizaciones n8n
